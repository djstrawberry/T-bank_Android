# Library Manager  
  
Android-приложение для учёта библиотечных материалов — книг, газет и дисков — с возможностью поиска и добавления книг через Google Books API.  
  
## Возможности  
- Просмотр, добавление и хранение элементов библиотеки (`Book`, `Newspaper`, `Disk`)  
- Поиск книг по автору/названию через Google Books API  
- Сортировка по имени и дате  
- Адаптивный интерфейс: раздельные экраны список/детали на телефоне, dual-pane режим в landscape  
  
## Стек  
- Kotlin  
- Clean Architecture (Presentation / Domain / Data)  
- Room — локальное хранение данных  
- Retrofit + Gson — работа с Google Books API  
- Coroutines  

## Запуск  
Стандартный Android-проект — откройте в Android Studio и запустите на эмуляторе/устройстве.
